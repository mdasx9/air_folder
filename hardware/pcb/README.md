# PCB files

Drop schematic, board, and manufacturing files here.

Suggested contents:

```
schematic.pdf              exported schematic (readable without an EDA tool)
board.kicad_pcb            native board file
board.kicad_sch            native schematic
gerbers/                   zipped Gerber + drill set sent to the fab
board-render-top.png       3D render, top
board-render-bottom.png    3D render, bottom
```

Include the PDF export even though the native files are here — it is what
lets a reviewer, a Hackster reader, or a hiring manager actually look at
the design in one click.
