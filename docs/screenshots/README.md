# Dashboard screenshots

These are referenced directly by the root README, which expects these
exact filenames:

| Filename | Shows |
|---|---|
| `live-monitor.png` | Live Monitor page — three rooms online, current readings |
| `event-logging.png` | Event Logging page — open event, room-state toggles |
| `analysis-export.png` | Event Analysis or Data Export — a real event visible in a chart |

Optional but high-impact:

| Filename | Shows |
|---|---|
| `dashboard-demo.gif` | 30–60 s screen recording; uncomment the line in the root README to display it |

## Tips

- Capture at a wide browser width (~1440 px) so the sidebar is expanded
  and charts are readable.
- Take the Event Analysis shot during or just after a real cooking event —
  a flat line proves nothing, a plume tells the whole story at a glance.
- Check each screenshot for anything you would rather not publish before
  committing it: window/AC state reveals habits, and timestamps reveal
  daily routine.
