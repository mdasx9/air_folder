## What the floor plan needs to show

It is the anchor figure — it has to make every later transport claim
legible at a glance:

- The three sensor node positions, labelled, with mounting height noted
- Room dimensions (or a scale bar)
- The corridor geometry connecting the rooms
- All doors, including the two living-room doors, and which are usually
  open or closed
- Windows, marked as the ones logged in `room_states`
- Kitchen exhaust fan position and where it vents
- North arrow or an outdoor-facing indication, if outdoor air matters

Export at 300 dpi or as a vector PDF/SVG if it is going into the paper;
also drop a PNG here so it renders in the README on GitHub.
